# دكتور شيرين — منصة الامتحانات الآمنة

منصة امتحانات أونلاين محمية ضد الغش والذكاء الاصطناعي، مصممة لدكتور شيرين.

## المميزات

- تسجيل الطالب بالاسم + رقم ولي الأمر
- رقم طالب تلقائي (مثل DR-2026-0001)
- مؤقت زمني مع تسليم تلقائي
- منع النسخ واللصق والزر الأيمن واختصارات لوحة المفاتيح
- كشف تبديل التبويبات (مع تحذير ثم تسليم تلقائي)
- وضع ملء الشاشة + علامة مائية باسم الطالب ورقمه
- خلط الأسئلة والاختيارات
- ظهور النتيجة فوراً للطالب بعد التسليم
- لوحة تحكم للأدمن لعرض كل النتائج (اسم / ID / درجة / رقم ولي الأمر / علامات الغش)

## التشغيل المحلي

cd dr-shereen-exam
npm install
npm run dev

افتح http://localhost:3000

- الصفحة الرئيسية: تسجيل الطالب
- /exam : صفحة الامتحان
- /results : النتيجة
- /admin : لوحة التحكم (كلمة المرور الافتراضية: shereen2026)

## تغيير الأسئلة

عدّل الملف: src/lib/exam-data.ts

أضف أو غيّر الأسئلة في المصفوفة questions، وحدد correctIndex (يبدأ من 0).

يمكنك أيضاً تعديل مدة الامتحان وعدد تبديلات التبويب المسموحة في config.

## النشر على Vercel + GitHub

1. أنشئ مستودع على GitHub وارفع المشروع.
2. اربط المستودع بـ Vercel.
3. (اختياري) أضف متغير بيئة ADMIN_PASSWORD بكلمة مرور قوية.
4. Deploy.

ملاحظة مهمة عن التخزين: حالياً النتائج تُحفظ في ذاكرة السيرفر (in-memory).
على Vercel قد تُفقد عند إعادة تشغيل الـ serverless function.
للإنتاج الحقيقي يُفضل ربط قاعدة بيانات (Supabase / MongoDB Atlas / Vercel Postgres).
يمكنني إضافتها لاحقاً بسهولة.

## الحماية من الـ AI

الحماية الحالية تقلل الغش العادي بقوة:
- منع النسخ / اللصق / التحديد
- منع الزر الأيمن و F12
- كشف الخروج من التبويب
- علامة مائية
- خلط الأسئلة

لكن لا يمكن منع طالب يستخدم جهاز ثاني أو AI محلي 100%.
أفضل دفاع إضافي هو تصميم أسئلة تطبيقية وليست حفظ فقط.
